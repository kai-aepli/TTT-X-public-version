🛈 The amount of layers determines how deep the tic-tac-toe field is. If there are two layers, each cell of the tic-tac-toe-field has another tic tac toe field in it, and so on. 🛈 The mode number determines how many layers above the lowest layer will be the playable area (green) that shifts after each move. In a default mode, the position of the placed X or O will also be the position of the according cell layer in which the next move has to take place. Just try it out. Within the modes "random", "upwards" and "downwards" the cell layer shifts after each move.
